💾 Резервная копия (со всеми фото, образами и календарём)

Данные хранятся в этом браузере на этом устройстве. Если очистить данные сайта или открыть страницу на другом устройстве, их не будет — поэтому скачивайте копию раз в неделю и загружайте её обратно через «Импортировать» ниже.

1. Выгрузить в wardrobe.json

Формат совместим со схемой из вашей Mac-инструкции (id, category, color, material, season, personas и т.д.)

Загрузить фото пачкой

Выберите сразу много фото — приложение само найдёт вещь по имени файла (например, T-01.jpg подставится в карточку с ID T-01). Можно выбирать несколько раз, если файлов много.

Применить анализ расхламления

Проставит вердикт, подгруппу, уверенность и «что сделать» по ID (T-05, SK-07, E1-04…). Для карантина поставит дату +30 дней. Вещи с другими ID пропускаются — список покажу ниже. Ручные правки по этим полям будут перезаписаны.

2. Загрузить обратно после обработки в ChatGPT/скрипта

Примите файл wardrobe_enriched.json (обновит роли/заметки по ID) или looks.json (создаст готовые образы). Импорт ищет вещи по полю id/customId — не меняйте его в скриптах.
